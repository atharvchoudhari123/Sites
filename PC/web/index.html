Setup & help

Nova PC uses QEMU for real virtualization. Install it separately on the host machine.

1

Install QEMU

macOS: brew install qemu

Windows: install a trusted QEMU Windows build and add its bin folder to PATH.

Debian / Ubuntu: sudo apt install qemu-system-x86 qemu-utils

2

Choose an OS ISO

Use installation media you are authorized to use. Windows activation and licensing remain your responsibility. Linux distributions often provide free installation images.

3

Create and run a VM

Choose CPU, RAM and virtual disk size, then start the VM in the desktop app. The guest OS installs into the virtual disk, not onto your Mac's physical drive.

Current limitationsCPU and RAM sliders configure the guest VM; they do not reserve resources while the VM is stopped. GPU passthrough is not included. Browser-only mode is a dashboard preview, not a QEMU emulator.
